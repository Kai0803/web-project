# 品牌識別

## 採用：方案 A — 彎頭（`logo-elbow.svg`）

90° 管件，銅色畫在**管口**（從端面看進去的管孔），不是沿著管身——沿著管身會讀成反光而非管件。

評選過程的比較圖與未採用的方案 C 已移除，需要時可由 git 歷史取回（commit `63438fa`）。

Logo 之後要調整時，改 `logo-elbow.svg` 後同步更新 `company_profile.logo_svg`（系統設定 → 公司資料），兩處都要改。

## 配色

| 用途 | 色碼 | 名稱 |
| --- | --- | --- |
| 主色 | `#1F3A4D` | 石墨藍 |
| 輔色 | `#B87333` | 銅 |

銅色取自冷媒銅管，是配管業實際使用的材料。空調業普遍使用制式天藍色，此配色可與同業區隔。

## 使用規則

- **單色場合**（傳真、蓋章、單色印刷）：將 `#B87333` 改為 `#1F3A4D`
- **深色背景**：管身改 `#FFFFFF`，銅色維持不變
- **最小尺寸**：24px。再小管口的銅色會糊掉，此時改用純單色版本
- **留白**：四周至少保留管身線寬的空間
