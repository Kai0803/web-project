# G1 需求釐清 — 第一階段：核心（客戶 / 專案 / 報價）

狀態：**待使用者確認**。標示「待確認」者為依公司規模推導的提案值，非使用者提供。

## 1. 目標

### 要解決的問題

公司規模 10–30 人、3–5 個工班的空調配管工程業，目前缺少把「客戶 → 案場 → 報價 → 合約」串起來的整合系統。第一階段建立這條主軸，作為後續供應鏈與專案執行模組的掛載點。

### 本階段要做

- 客戶主檔（基本資料、聯絡人、往來紀錄）
- 專案 / 案場主檔（地點、類型、狀態、負責人）
- 報價單（品項明細、金額計算、版本管理、核准流程）
- 報價轉合約
- 使用者帳號與角色權限

### 本階段明確不做

- 料件主檔、BOM、採購單、進料、庫存（第二階段）
- 排程、工班派工、工時回報、進度追蹤（第三階段）
- 請款、發票、會計系統整合
- 對外（客戶 / 供應商）入口 — 見第 5 節待決項
- 原生行動 App（但網頁需在手機可用）

## 2. 非功能需求

### 使用規模（依 10–30 人、3–5 工班推導，待確認）

| 項目 | 估計值 |
| --- | --- |
| 同時上線使用者 | 10–15 |
| 年專案數 | 150–300 |
| 5 年累計專案 | 750–1,500 |
| 每專案報價單版本數 | 1–5 |
| 5 年累計報價單 | 約 3,000–7,500 |
| 每張報價單品項數 | 20–100 |
| 5 年累計報價明細列 | 約 30 萬列 |
| 客戶主檔 | 數百筆 |

第一階段資料量小，單一 Postgres 實例綽綽有餘。真正的資料量壓力在第二階段的 BOM 明細與第三階段的工時紀錄，以及施工照片的儲存（預估每年 3,000–30,000 張），這些在對應階段的 G1 再行評估。

### 效能（待確認）

- 一般頁面 P95 回應時間 < 500 ms
- 報價單列表、專案列表需分頁，不一次載入全部
- 報表類查詢可放寬至 P95 < 3 s

### 可用性（待確認）

- 內部系統，工作時間（平日 08:00–20:00）可用即可，非 24/7
- 允許夜間停機維護
- 資料庫每日備份，可接受的資料遺失上限為 24 小時

### 安全性

- 僅公司內部帳號可登入
- 報價金額與成本屬敏感資料，需依角色控管可見範圍
- 所有變更需可追溯（誰在什麼時候改了報價）

## 3. 成功條件

第一階段完成的驗證方式：**拿一個真實案子從頭走完一遍**。

1. 建立客戶資料
2. 建立專案 / 案場，關聯到該客戶
3. 開立報價單，輸入品項與金額
4. 修改報價產生新版本，保留舊版可查
5. 報價核准後轉為合約
6. 輸出可交付給客戶的報價單檔案

其他條件：

- `cargo clippy` 與 `tsc --noEmit` 無警告
- 核心業務邏輯（金額計算、版本管理、權限判斷）有測試覆蓋正常 / 邊界 / 錯誤路徑
- 以 `podman kube play` 可在本機完整啟動（應用程式 + Postgres）

## 4. 範圍邊界

### 會動到

全新的 repo 結構。後端 Rust、前端 Vue 3 + TypeScript、資料庫 PostgreSQL。

### 不動

- 既有 Node.js 版冷氣清洗預約系統（commit `836efb1`–`520d847`）保留於 git 歷史，不再維護，程式碼不沿用。業務範圍不同（B2C 到府清洗 vs B2B 工程專案）
- `.claude/` 下的 skill 與 agent 設定

### 部署

本機以 `podman kube play` 啟動應用程式與 Postgres 兩個容器，後續由使用者自行移至 server。資料庫連線一律由環境變數提供，不寫死。

## 5. 待決項

### 對外入口（阻擋 G2 開始）

使用者於 G1 問卷同時選擇了互斥的三個選項：「純內部系統，不對外」、「客戶可查專案進度」、「客戶可線上詢價」。

此項影響認證模型、CORS 設定、部署拓樸（能否整套置於內網 / VPN 後方），以及資料模型是否需要從一開始就預留客戶可見性欄位，因此必須在 G2 設計前確定。

建議解法：**第一階段純內部，但資料模型與認證從一開始就預留對外擴充**（客戶帳號型別、專案與報價的對外可見性欄位）。如此第二、三階段要加客戶入口時不需改動既有結構，也不必在第一階段就承擔對外曝露的安全成本。

## 6. 假設

以下為推導值而非使用者確認事項，若有誤請於確認時修正：

- 公司目前無既有系統需要資料移轉（若有舊 Excel / 系統資料要匯入，需納入範圍）
- 報價幣別僅新台幣，無多幣別需求
- 無多分公司 / 多組織需求，單一公司單一帳本
- 稅率處理為台灣營業稅 5%，報價單需區分未稅 / 含稅
